# Daily Bilingual Brief — Editorial Contract

Produce a high-density daily tariff brief for Discord now and X later.

## Output

- `🇵🇱 POLSKI`: one bullet per substantive event.
- `🇬🇧 ENGLISH`: the same bullets in the same order.
- `Źródła / Sources`: numbered official links matching the bullets.
- Each bullet is exactly one dense, natural sentence—not a title plus explanation.
- Include every substantive event in the daily window, but merge duplicate documents about the same action.

## Sentence content

Maximize factual payload: actor, action, exact rate/value when sourced, product or vessel, origin/target country, and effective date or status when relevant.

Good:
- `USA nakłada 20% cła na import miedzi z Chin od 1 września.`
- `US imposes a 20% tariff on copper imports from China effective September 1.`

Never invent a rate or effective date. Never describe an investigation, proposal, review, or suspension as an imposed tariff. Skip routine corrections and administrative notices unless they materially change a measure.

## Style

Concrete, vivid and plain-language; no bureaucratic titles, generic commentary, methodology prose, or technical collector statistics in the lead. Keep each sentence suitable for a standalone X post. Sources belong in the source block now and in replies/comments when X delivery is enabled.
